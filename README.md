## 💡 Engineering Highlights

* Built **real-time WebSocket architectures** with room-based broadcasting and concurrent state synchronization
* Developed **offline-first mobile workflows** with persistent queues, automatic synchronization and conflict resolution
* Implemented **JWT access and refresh token rotation** with revocation and multi-level RBAC
* Migrated React single-page applications to **Next.js with server-side rendering**
* Created containerized **CI/CD pipelines** with automated testing, deployment and rollback support
* Improved frontend performance using code splitting, memoization and bundle optimization
* Built REST APIs using **Node.js, Express, Python and FastAPI**
